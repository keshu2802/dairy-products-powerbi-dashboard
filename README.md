# Dairy Products Analytics Dashboard

## 📊 Project Overview

An interactive **Power BI dashboard** developed to analyze dairy product sales and business performance. The project involves data cleaning, transformation, analysis, and visualization to present key business metrics and trends.

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization

## 📈 Dashboard Features

* Sales performance analysis
* Product-wise analysis
* Business performance insights
* Interactive charts and visualizations
* Dynamic filtering and reporting

## 🔍 Key Skills Demonstrated

* Data Cleaning
* Data Transformation
* Data Analysis
* Dashboard Development
* Data Visualization
* Business Intelligence
